Features (Implemented vs Planned)

  • ✅ FastAPI + PostgreSQL backend APIs for events, metrics, alerts, incidents, and evaluation
  • ✅ Deterministic replay flow that simulates streaming-style ingestion for demo scenarios
  • ✅ Blended anomaly scoring (Z-score, Isolation Forest, rolling baseline, minute-bucket seasonal proxy)
  • ✅ React dashboard for KPI monitoring, anomaly trends, alert triage, and incident workflow
  • 🔲 External Slack, PagerDuty, and email alerting integrations
  • 🔲 Full seasonal decomposition and broader production observability instrumentation
  • 🔲 Real streaming ingestion stack (Kafka/Kinesis/WebSocket-based pipeline)
